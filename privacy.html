Privacy Policy

Last updated: November 2026

Personal TikTok Upload Tool ("the Tool") is a private application used only by its owner.

Data the Tool handles

When the owner authorizes the Tool with TikTok Login Kit, TikTok issues an access token and a refresh token for the owner's own account. These tokens are stored only on the owner's own computer and are used only to upload the owner's videos through the TikTok Content Posting API.

What the Tool does not do

The Tool does not collect data about any other person, does not use cookies or analytics, does not run advertising, and does not sell, share or transfer data to any third party.

Revoking access

The owner can revoke the Tool's access at any time from the TikTok app settings (Manage app permissions).
